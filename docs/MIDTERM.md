## Submission assembly

The course requires one ZIP, at most 100 MB, containing:

1. `campus_find_demo.mp4`: live workflow recording, at most 60 seconds.
2. `repository_link.txt`: the official submission repository URL, accessible to assessors.
3. `status_sheet.docx` (editable) or `status_sheet.pdf`: the one-page status sheet following the companion template.

The official submission repository link and README are deliberately deferred.
Supply both before submission; a placeholder does not meet the access and
reproduction criterion. The final README must document setup, a core example
input and expected output. The existing RUNNING guide can support that work.

Confirm each member's actual completed contribution before finalising the sheet.
Proposed future roles are not evidence of completed work. The local review package
is kept outside this repository while the official submission
URL is pending and the team reviews its contribution entries. Do not put student numbers, email addresses, credentials,
or intermediate capture frames into the public webpage or video.

Submit by 26 October 2026, using the exact Moodle cutoff, and check the group receipt.

The two-week plan follows the 26 October deadline: 27 October–9 November 2026.
Milestones fall on 30 October, 4 November and 9 November. Newly assigned
responsibilities are explicitly separated from completed contributions.
